# BREACH — 5v5 파괴 FPS

브라우저에서 바로 하는 5대5 전술 FPS. 벽을 쏘면 구멍이 나고, 그 구멍으로 보고 쏜다.
설치 없음. 링크만 공유하면 같이 플레이.

**플레이: https://jisanjun.github.io/breach/**

## 같이 하는 법

1. 한 명이 **방 만들기**를 누른다 (호스트).
2. 나온 초대 링크를 공유한다. 최대 10명, 팀은 자동 배정되고 로비에서 바꿀 수 있다.
3. 호스트가 **매치 시작**. 라운드마다 공수 교대, 4라운드 선승.

호스트가 탭을 닫으면 방이 사라진다. 혼자 연습(봇전)도 있다.

## 규칙

- **공격**: 붉은 컨테이너가 있는 방에 디퓨저를 설치하고 30초 지키거나, 방어팀 전멸.
- **방어**: 3분 버티기, 공격팀 전멸, 또는 설치된 디퓨저 해제.
- 준비 단계 25초: 공격팀은 드론으로 정찰, 방어팀은 벽 보강.
- 밝은 벽과 나무 바리케이드는 총알이 뚫는다. 구멍이 많아지면 벽이 통째로 무너진다.

## 조작

| 키 | 동작 |
|---|---|
| WASD / Shift / C | 이동 / 달리기 / 앉기 |
| Q / E | 좌우 기울이기 |
| 좌클릭 / 우클릭 | 사격 / 조준 |
| R, 1 / 2 | 장전, 무기 교체 |
| V | 근접 타격 (바리케이드는 3타) |
| G | 오퍼레이터 가젯 |
| F 꾹 | 디퓨저 설치 / 해제 |
| O | 준비 단계에서 오퍼레이터 변경 |

## 개발

파일 하나(`index.html`)가 전부다. 빌드 없음.

```bash
python -m http.server 8765
```

`http://localhost:8765/#test` 로 열면 콘솔에서 자체 점검이 돈다.
멀티플레이는 PeerJS(WebRTC)로 호스트 브라우저가 중계한다.
