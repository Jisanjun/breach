# BREACH — 5v5 파괴 FPS

브라우저에서 바로 하는 5대5 전술 FPS. 벽과 바닥을 쏘면 구멍이 나고, 그 구멍으로 보고 쏜다.
맵은 시즈의 '하우스'를 본뜬 3층 주택(지하·1층·2층)이다.
설치 없음. 링크만 공유하면 같이 플레이.

**플레이: https://jisanjun.github.io/breach/**

## 같이 하는 법

1. 한 명이 **방 만들기**를 누른다 (호스트).
2. 나온 초대 링크를 공유한다. 최대 10명, 팀은 자동 배정되고 로비에서 바꿀 수 있다.
3. 호스트가 **매치 시작**. 라운드마다 공수 교대, 4라운드 선승.

호스트가 탭을 닫으면 방이 사라진다. 라운드 도중에 들어온 사람은 관전하다가 다음 라운드부터 뛴다.
사람이 모자라면 로비의 **빈 자리 봇**으로 팀을 채울 수 있다 (봇은 호스트의 브라우저가 움직인다).
**혼자 연습**은 봇이 양 팀을 채우는 5대5 매치, **혼자 1대5**는 상대 팀만 봇 다섯인 매치다
(로비의 빈 자리 봇에서 "사람 없는 팀만 5명"을 골라도 같다).

## 규칙

- **공격**: 바닥이 붉은 방에 디퓨저를 설치하고 35초 지키거나, 방어팀 전멸.
- **방어**: 3분 버티기, 공격팀 전멸, 또는 설치된 디퓨저 해제.
- 준비 단계 30초: 공격팀은 드론으로 정찰, 방어팀은 벽 보강. 목표 방과 공격 진입 방향은 라운드마다 바뀐다.
- 밝은 벽, 문 바리케이드, 창문 판자는 총알이 뚫는다. 구멍이 많아지면 통째로 무너진다.
  벽 속 샛기둥과 창틀은 남는다. 벽돌·콘크리트·강철은 안 뚫린다.
- 머리에 맞으면 한 방. 벽을 뚫고 맞히면 피해가 줄어든다.
- 맵은 둘, 홈 화면에서 고른다 (초대 링크에 맵이 들어간다): **하우스** (지하·1층·2층)와 **해안선** (1층·2층, 가운데 안뜰은 하늘이 뚫려 있다).
  방·벽·계단·해치와 "총알이 뚫는 바닥" 구역을 공개된 층별 도면에 맞춰 직접 그렸다. 아래 설명은 하우스 기준.
  계단은 서쪽·중앙·남쪽과 지하 계단. 동쪽 진입로로 내려가면 지하 차고 문(부숴야 열린다).
- **레펠** (공격팀, Space): 집 바깥벽 앞에서 줄을 걸고 W/S 로 오르내린다. 줄에 매달린 채 쏠 수 있고,
  판자가 떨어진 창문·뚫린 벽·발코니 앞에서 Space 로 들어간다. 열린 창문은 바닥에서도 누구나 Space 로 넘는다.
- 회색 블록 벽은 안 부서지는 내벽이다. 바닥도 나무인 곳만 뚫리고 회색(타일·콘크리트)은 안 뚫린다.
- **나무 바닥은 총알이 뚫는다.** 위층에서 아래로, 아래층에서 천장으로 쏠 수 있고 구멍으로 내려다볼 수 있다 (장선은 남는다).
- 바닥의 해치를 열면 아래층으로 뛰어내린다. 위에서 내려다보거나 아래에서 올려다보며 G(폭약·해머·보강) 또는 V(3타). 폭발에도 열린다.
- 화면 위쪽에 지금 있는 방 이름이 나온다 (예: 2층 자동차 방).

## 오퍼레이터

| 공격 | 무기 | 가젯 (G) | 투척 (T) |
|---|---|---|---|
| 돌파병 | 돌격소총 / 권총 | 돌파 폭약 ×3 | 수류탄 |
| 해머 | 산탄총 / 기관단총 | 벽을 한 방에 부수는 해머 ×8 | 섬광탄 ×2 |
| 용접병 | 돌격소총 / 권총 | 보강벽도 뚫는 폭약 ×2 | 연막탄 ×2 |
| 지정사수 | 지정사수소총 / 권총 | 돌파 폭약 ×1 | 클레이모어 ×2 (바닥에 설치, 적이 밟으면 폭발) |

| 방어 | 무기 | 가젯 (G) | 투척 (T) |
|---|---|---|---|
| 보강병 | 기관단총 / 산탄총 | 벽 보강 ×4 | 설치형 방패 (낮은 탄을 막는 엄폐물, Space 로 넘는다) |
| 방탄병 | 돌격소총 / 권총 | 방탄판(체력 150), 벽 보강 ×2 | 철조망 ×2 (적이 느려진다, V 로 끊거나 폭발로 제거) |
| 감지병 | 기관단총 / 권총 | 벽 너머 적 감지 (누르고 있기) | C4 (T 로 던지고 T 로 기폭, 바닥도 뚫는다) |
| 함정병 | 산탄총 / 권총 | 문에 폭발 함정 ×3 | 충격 수류탄 |

체급은 셋이다: 가벼움(체력 100, 빠름 — 돌파병·감지병), 중간(체력 110), 무거움(느림 — 방탄병).
무기의 피해·연사·탄창은 실제 시즈의 같은 종류 무기 수치를 따른다. 거리가 멀어지면 피해가 줄어든다
(산탄총은 4칸부터 급격히, 권총·기관단총·소총 순으로 멀리 간다). 머리에 맞으면 거리와 상관없이 한 방이다 (산탄총 제외).

| WASD / Shift / C | 이동 / 달리기 / 앉기 |

## 개발

빌드 없음. `index.html` 이 `js/` 의 스크립트를 순서대로 불러온다.

| 파일 | 내용 |
|---|---|
| `js/maps.js` | 맵 데이터 (층별 문자 격자, 방 이름). 도면에서 옮기는 스크립트가 만든 파일이라 직접 고치지 않는다 |
| `js/core.js` | 캔버스, 저장 설정, 맵 읽기 (세 층을 한 격자에 이어서 저장, 높이로 쌓아 그림) |
| `js/gfx.js` | 절차 생성 텍스처·스프라이트 |
| `js/audio.js` | 합성 효과음 |
| `js/world.js` | 벽·바닥 파괴, 층을 관통하는 광선 판정, 총알, 수류탄, 함정 |
| `js/game.js` | 무기, 오퍼레이터, 봇 AI, 라운드 |
| `js/net.js` | 멀티플레이 (PeerJS, 호스트 브라우저가 중계·심판·봇 조종) |
| `js/render.js` | WebGL2 월드 렌더러 (구멍은 마스크 텍스처로 실제 투과) + 2D 오버레이 |
| `js/models.js` | three.js 층: 애니메이션 캐릭터 모델, 1인칭 총 모델 (로드 실패 시 스프라이트로 대체) |
| `js/ui.js` | 입력, HUD, 메뉴 |
| `js/main.js` | 프레임 루프, 자체 점검 |

```bash
python -m http.server 8765
```

`http://localhost:8765/#test` 로 열면 콘솔에서 자체 점검이 돈다 (`selfTest done` 만 나오면 통과).
배포할 때는 `index.html` 의 `V` 를 올린다 (스크립트 주소의 버전 도장).
